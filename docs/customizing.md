# Customizing

Everything about the weather itself lives in [`Data.lua`](../Data.lua), which is safe to edit.
After editing, `/reload` in game.

> Weather is shared because everyone runs the same data. If you change `Data.lua` for yourself,
> your sky will differ from other players'. Send changes upstream as a pull request so everyone gets them.

## Give a zone a climate

Add the zone's English name to `ns.Zones`:

```lua
ns.Zones = {
	...
	["Feralas"] = "jungle",
	["My New Zone"] = "highland",
}
```

The name must match what `GetRealZoneText()` returns, which is the zone name shown above the minimap.
Zones that are not listed use `ns.DEFAULT_CLIMATE` (`temperate`).

## Add a warm building

If a building has a fire or a forge, add its subzone name (shown above the minimap while you're inside) to `ns.WarmPlaces`:

```lua
ns.WarmPlaces = {
	["The Great Forge"]        = "forge",
	["Thunderbrew Distillery"] = "hearth",
	["My Smithy"]              = "forge",
}
```

How hot each source is lives in `ns.HeatSources` (`temp`, `hold`, `hum`, `label`).

## Tune or add a climate

```lua
ns.Climates = {
	highland = { temp = 10, swing = 10, season = 9, hum = 58, wind = 18, dir = 280,
	             sky = { {"clear",2.5}, {"fair",3}, {"overcast",2}, {"drizzle",1}, {"rain",1.2}, {"storm",0.5} } },
}
```

| Field | Meaning |
|---|---|
| `temp` | Yearly mean temperature (°C) |
| `swing` | Day/night range (°C) |
| `season` | Summer/winter amplitude (°C) |
| `hum` | Mean humidity (%) |
| `wind` | Mean wind (km/h) |
| `dir` | Prevailing wind, degrees it blows **from** (0 = N, 90 = E, 180 = S, 270 = W) |
| `sky` | Conditions from fairest to foulest, `{ name, weight }`. Weights are relative: `{"clear",3}` happens three times as often as `{"rain",1}` |
| `indoor = true` | No sky, no wind |

Keep the `sky` ladder ordered from fair to foul. The barometer and the "weather is coming" trend
rely on that order.

For precipitation in cold climates, list the rain forms (`drizzle`, `rain`, `storm`). They become
`flurries`, `snow` and `blizzard` below -1 °C automatically.

## Change a sky condition

`ns.Conditions` holds each condition's day and night names, the flavour text, and how it changes
the base climate:

| Field | Meaning |
|---|---|
| `temp` | °C added (clear and haze apply it in reverse at night) |
| `hum` | % added to humidity |
| `windMul` | Multiplies the climate's wind |
| `wind` | km/h of gusts added on top |

Adding a brand-new condition also needs art: a `wx_<name>_day` and a `wx_<name>_night` texture (see below).

## Orb sky and time of day

`ns.SkyByHour` lists keyframes through the day: the hour, the sky colour, the horizon glow colour
and the glow's strength. The orb blends smoothly between neighbouring rows, so adding a row at
`17` with a pinker glow, for example, gives a pink late afternoon.

`ns.SUNRISE` and `ns.SUNSET` (5.5 and 21) set when the sun crosses the orb. The moon crosses it the rest of the time.

`ns.SkyMoods` changes that sky for the weather: `desat` pulls it toward grey, `dark` dims it,
`tint` + `amount` blend it toward a colour, and `glow` scales the horizon glow. `ns.SkyMood` decides
which mood each condition uses. `ns.StarrySky` lists the conditions that let stars show at night.

## Art

All textures in `Media/` are generated by [`tools/make_icons.py`](../tools/make_icons.py):
plain Python 3 with no dependencies.

```
python tools/make_icons.py      # writes Media/*.tga
python tools/preview_icons.py   # writes docs/images/icons.png to check the result
```

| Texture | Size | Purpose |
|---|---|---|
| `sky` | 128×128 | Grey radial gradient, tinted in game with the sky colour of the hour |
| `horizon` | 128×128 | Glow rising from the bottom edge, tinted for dawn, evening and dusk |
| `stars` | 128×128 | Night sparkles, shown on clear, fair and hazy nights |
| `sun`, `moon_0` to `moon_7` | 128×128 | The sun, and the moon in each phase (0 new, 4 full) |
| `wx_<condition>_day` / `_night` | 128×128 | Weather drawn over the sun or moon. Clear has none |
| `temp_freezing`, `cold`, `mild`, `warm`, `hot` | 64×64 | Temperature badges |
| `icon` | 128×128 | Addon-list icon (`## IconTexture` in the TOC), in the shared ImmerseMe frame |

How the orb is assembled in game (`UpdateOrb` in [`UI.lua`](../UI.lua)), back to front:

1. The sky gradient, tinted by the hour and the weather (`ns.SkyAt` in [`Core.lua`](../Core.lua)).
2. The horizon glow, strongest at dawn and dusk.
3. Stars, on clear nights.
4. The sun or the moon on its arc (`ns.ArcAt`): it rises low on the left, is highest halfway through
   the day or night, and sets low on the right. A low sun is tinted orange.
5. The weather overlay.
6. The gold ring: Blizzard's own ring when drawn on the stock icon.

The style follows the stock day/night icon: deep radial skies, a heraldic gold sun with wavy flame
rays and dark-amber outlines, a lavender moon with a soft halo, and four-point sparkle stars.
Keep overlays inside the circle and remember the sun and moon move, so weather that should let
them show through needs to leave some sky open.

New or replaced texture files need a **full game restart**. `/reload` does not load them.
